## How to run
Open any case-study folder and double-click its `index.html` file. The page opens in a web browser. No framework, server, or installation is required.

## Syllabus mapping
- **Unit I:** HTML structure, elements, CSS syntax, classes, text alignment, colors and backgrounds.
- **Unit II:** Typography, box model, width, height, borders, padding, margin, lists, images and responsive UI design.
- **Unit III:** HTML5 semantic elements, hyperlinks, anchor navigation and internal page links.

All projects use beginner-friendly HTML5 and CSS3. Forms and contact/order links are front-end demonstrations; no server-side processing is included.
