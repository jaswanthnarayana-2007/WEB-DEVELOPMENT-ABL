# Screenshot guide

The `page-preview.svg` files in each case-study `screenshots/` folder are rendered previews generated from the HTML and CSS source. They are **not genuine browser screenshots**.

If your lecturer requires browser screenshots:
1. Open the project folder.
2. Double-click `index.html` to open it in Chrome or Edge.
3. Press `Win + Shift + S` and select the visible webpage.
4. Save the image as `browser-screenshot.png` in that case study's `screenshots/` folder.
5. Repeat for all three projects. Capture additional sections by scrolling and taking another screenshot.

The formatted PDF currently includes rendered previews and clearly labels them. Replace them with browser screenshots if required by your lecturer.
