# Screenshot Guide (Windows)

1. Open the downloaded repository folder.
2. Open one case-study folder.
3. Double-click its `index.html` file to open it in your browser.
4. Scroll to the section you want to capture.
5. Press `Windows + Shift + S` and select the webpage.
6. Save the image in that project's `screenshots` folder.
7. Repeat for all three websites.
8. Insert the screenshots into the report document and export it as PDF.

Suggested captures: portfolio homepage and skills; bakery homepage and products; tourism homepage and destinations.
