# Genuine browser screenshot guide

The `page-preview.svg` files in the case-study `screenshots/` folders are rendered previews made from the project source. They are **not genuine browser screenshots**.

To capture the required evidence:

1. Open the published website in Chrome or Edge.
2. Press **Win + Shift + S** and select the webpage area.
3. Save the image as `browser-screenshot.png` in the matching case-study `screenshots/` folder.
4. Repeat for each case study. Scroll down and capture more sections if your lecturer expects full-page evidence.
5. Add the saved image files to the matching GitHub folders and commit the changes.
