## 3. Syllabus mapping

- **Unit I:** HTML document structure and elements; CSS syntax, classes, text alignment, colors, and backgrounds.
- **Unit II:** Typography, box model, width, height, borders, padding, margin, lists, images, and responsive presentation.
- **Unit III:** HTML5 semantic elements, hyperlinks, anchor navigation, and internal page links.

## 4. How to run the projects

1. Open this GitHub repository.
2. Open the folder for the required case study.
3. Open `index.html` in Chrome, Edge, or another web browser.
4. Use the navigation links to explore the webpage.

No external framework or server installation is required.

## 5. Testing and observations

Each website was opened in a browser and its main page content and navigation layout were reviewed. The websites are static frontend demonstrations. Contact, order, and form-like controls do not submit data to a backend service.
